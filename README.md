## Working with the projects

Each project may have its own dependencies and run instructions. Check the project directory for its `README`, dependency manifest, and entry point before installing packages or running it. Avoid installing dependencies globally; use a project-specific virtual environment where applicable.

For Jupyter notebooks, install Jupyter in the relevant environment and open the notebook from its project directory.

## Repository structure

- `Python/Console Apps/` — command-line applications and utilities
- `Python/Frameworks/` — framework-based applications and notebooks

The repository name is retained for compatibility with existing links and history.
